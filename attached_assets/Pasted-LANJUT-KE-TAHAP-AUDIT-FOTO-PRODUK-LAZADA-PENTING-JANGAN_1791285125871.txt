TOLONG AUDIT IMPLEMENTASI SEKARANG:

1. Periksa endpoint/API Lazada yang saat ini digunakan ZETAS untuk mengambil daftar pesanan dan detail pesanan.

2. Periksa response order/item yang sudah diterima aplikasi.
   Cari apakah sudah tersedia:
   - order_id
   - order_item_id
   - item_id
   - sku_id
   - seller_sku
   - product_id
   - item information
   - image URL
   - atau identifier lain yang bisa digunakan untuk mengambil foto produk.

3. Periksa seluruh service/repository Lazada yang sudah ada.
   Tentukan apakah aplikasi saat ini sudah mempunyai mekanisme untuk:
   - GetOrderItems / GetMultipleOrderItems
   - GetProductItem / GetProducts
   - atau endpoint produk Lazada lain.

4. Periksa mapping data dari response Lazada sampai ke frontend.
   Jelaskan apakah foto produk sebenarnya sudah tersedia tetapi belum diteruskan ke UI.

5. Periksa kebutuhan API permission Lazada.
   Jika foto dapat diperoleh dari API yang sudah memiliki permission, katakan bahwa tidak perlu permission tambahan.
   Jika membutuhkan permission tambahan, sebutkan:
   - nama API
   - permission/API Permission Group yang diperlukan
   - bagian Lazada Developer tempat permission tersebut diajukan.

6. Periksa apakah penggunaan URL gambar Lazada langsung di frontend memungkinkan berdasarkan implementasi aplikasi saat ini.

7. Jangan membuat solusi baru jika data yang dibutuhkan sebenarnya sudah tersedia.
