2. ANIMASI
============================================================

Tambahkan animasi ringan dan profesional.

JANGAN menggunakan animasi berlebihan.

Gunakan:

- fade-in ringan
- slight slide-up
- stagger animation pada card dashboard
- smooth filter transition

- card press feedback

Hormati:

Jika user mengaktifkan reduced motion,
kurangi/nonaktifkan animasi yang tidak penting.

JANGAN menambahkan library animasi baru jika tidak diperlukan.

HORIZONTAL FILTER
------------------------------------------------------------

Pada mobile, JANGAN memaksa semua chip masuk ke satu layar.

Gunakan horizontal scrolling.

Contoh:

[ Semua ] [ Belum Dibayar ] [ Diproses ] [ Selesai ] [ Dibatalkan ]

Jika layar tidak cukup,
chip boleh melewati sisi kanan dan dapat digeser horizontal.

Ketentuan:

- tinggi chip sekitar 44–48px
- tap target nyaman
- font tetap mudah dibaca
- padding horizontal cukup
- tidak terlalu besar
- tidak terlalu kecil
- active state jelas
- tidak ada chip terpotong secara tidak sengaja
- horizontal scrolling smooth
- scrollbar tidak perlu ditampilkan
- posisi awal selalu di "Semua"

JANGAN mengecilkan font atau chip secara berlebihan hanya untuk
memaksa semua filter masuk satu baris.

PRIORITAS:
Usability > memaksa semua item terlihat sekaligus.

Pada desktop/tablet:
Jika ruang cukup, tampilkan semua filter tanpa scrolling.
