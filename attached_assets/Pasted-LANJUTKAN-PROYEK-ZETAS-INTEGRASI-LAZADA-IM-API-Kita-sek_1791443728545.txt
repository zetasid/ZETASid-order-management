LANJUTKAN PROYEK ZETAS – INTEGRASI LAZADA IM API

Kita sekarang sudah menemukan dokumentasi resmi Lazada Open Platform untuk endpoint IM yang sebelumnya belum terverifikasi.

JANGAN langsung mengubah production, jangan deploy, jangan commit, dan jangan membuat asumsi terhadap parameter yang belum terdokumentasi.

Tujuan tahap ini hanya mengimplementasikan dan menguji 2 endpoint resmi berikut:

1. ReadSession
POST /im/session/read

Parameter wajib:
- session_id
- last_read_message_id

2. SendMessage
POST /im/message/send

Parameter wajib:
- session_id
- template_id

Untuk pesan teks:
- template_id = 1
- txt = isi pesan

Response SendMessage yang terdokumentasi:
- err_code
- success
- err_message
- data.current_time
- data.message_id
- data.template_id

Gunakan endpoint Indonesia yang sudah digunakan ZETAS:
https://api.lazada.co.id/rest

ATURAN PENTING:

1. Pertahankan mekanisme autentikasi dan signature Lazada yang sudah ada di ZETAS.
2. Jangan membuat mekanisme signature baru jika helper yang sudah ada bisa digunakan.
3. Jangan mengubah OAuth/credential/token yang sudah berjalan.
4. Jangan mengubah LAZADA_APP_SECRET, LAZADA_IM_APP_SECRET, encryption key, atau credential apa pun.
5. Jangan mengubah UI.
6. Jangan membuat database chat baru pada tahap ini.
7. Jangan membuat long-polling/worker terlebih dahulu.
8. Jangan membuat Push/Webhook terlebih dahulu.
9. Jangan mengubah Order Push yang sudah berjalan.
10. Jangan menghapus atau merusak endpoint IM yang sudah ada:
   - /im/session/list
   - /im/session/get
   - /im/message/list
11. Jangan melakukan API call nyata ke akun Lazada saya selama tahap development/test kecuali saya meminta secara eksplisit.
12. Gunakan mock/fixture untuk test.
13. Jangan mengarang parameter atau response yang tidak ada dalam dokumentasi.

Jika route belum diperlukan, cukup siapkan client/service terlebih dahulu.

D. Tambahkan test fixture/mock untuk:
- ReadSession success
- ReadSession error
- SendMessage text success

E. Pastikan:
