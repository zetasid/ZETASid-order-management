2. TYPOGRAPHY
Poles typography agar terlihat lebih premium dan profesional.

- Heading: tegas dan jelas.
- Statistik/angka: bold dan mudah dibaca.
- Body text: nyaman dibaca.
- Secondary text: lebih soft tetapi tetap kontras.
- Order ID tetap menggunakan monospace.
- Jangan menggunakan terlalu banyak jenis font.
- Pertahankan konsistensi seluruh halaman.

3. ANIMASI RINGAN
Tambahkan micro-interaction yang halus:

Dashboard:
- card muncul dengan fade/slide ringan.
- angka statistik dapat menggunakan count-up ringan.
- jangan membuat animasi berlebihan.

Pesanan:
- card mempunyai press/tap feedback ringan.
- perpindahan filter menggunakan transisi pendek.
- tombol Sinkronkan Pesanan mempunyai loading state yang jelas ketika aktif.

Detail Pesanan:
- section/card masuk dengan fade/slide ringan.
- tombol copy memberikan feedback singkat setelah berhasil.

Pengaturan:
- card muncul dengan transisi ringan.
- status system menggunakan indikator yang halus.

Gunakan animasi sekitar 150–250ms.
Hindari animasi berulang yang mengganggu.
Hormati prefers-reduced-motion.
