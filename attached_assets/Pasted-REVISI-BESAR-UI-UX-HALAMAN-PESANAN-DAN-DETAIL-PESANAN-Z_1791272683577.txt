"Baca order Lazada — READ-ONLY"
menjadi kartu besar seperti sekarang.

Fungsi membaca/sinkronisasi order tetap dipertahankan, tetapi UI-nya harus jauh lebih ringkas.

Gunakan struktur:

HEADER
"Pesanan"

SUBTITLE singkat:
"Kelola pesanan digital Lazada."

SEARCH
Cari ID pesanan atau produk

FILTER STATUS:
Semua
Menunggu
Diproses
Selesai
Dibatalkan

Tampilkan jumlah:
"28 pesanan"

ORDER CARD:

Setiap kartu harus mempunyai:
- Foto produk Lazada jika tersedia
- Nama produk
- Order ID
- Status
- Harga
- Waktu order
- Chevron untuk membuka detail

Contoh:

[Foto produk]

Gopay Saldo Top Up
oleh Zetas.id

#2787170078500594

Rp60.000

Jangan menampilkan terlalu banyak informasi teknis di kartu.

==================================================
2. DETAIL PESANAN
==================================================

Halaman Detail Pesanan harus benar-benar didesain ulang.

HEADER:

←
Detail Pesanan

Jangan hanya menampilkan data mentah.

==================================================
3. STATUS
==================================================

Buat status sebagai card yang jelas.

Contoh:

STATUS PESANAN

Dibatalkan

Gunakan warna status yang konsisten:
- Menunggu = orange
- Diproses = biru
- Selesai = hijau
- Dibatalkan = merah

Jangan menggunakan bahasa Inggris "canceled/confirmed"
sebagai tampilan utama jika bisa diterjemahkan.

Gunakan:
Menunggu
Diproses
Selesai
Dibatalkan

==================================================
4. PRODUK
==================================================

Buat card PRODUK.

Jika foto produk tersedia dari data Lazada, tampilkan foto tersebut.

Contoh:

[ FOTO PRODUK ]

Gopay Saldo Top Up oleh Zetas.id
Praktis, Aman, Langsung Masuk

Variasi: Rp60.000

Foto produk harus terlihat jelas tetapi tidak terlalu besar.

==================================================
7. AKSI ORDER
==================================================

Untuk order yang dapat diproses:

Buat tombol utama besar:

PROSES / KIRIM DIGITAL

Gunakan warna orange ZETAS.

Sebelum proses, tampilkan confirmation dialog:

"Konfirmasi Pesanan"

Produk
Tujuan
Nominal

"Pastikan data tujuan sudah benar."

[Batal] [Kirim Digital]

Saat proses berlangsung:
- tombol disabled
- tampilkan loading
- cegah double click
- jangan memungkinkan order terkirim dua kali

Untuk order selesai:
jangan tampilkan tombol proses aktif.

Untuk order dibatalkan:
jangan tampilkan tombol kirim digital.
